# 隐私与公开发布检查

## 公开内容

应用源码、启动脚本、依赖、测试、文档，以及 `scripts/generate_demo_images.py` 用 Pillow 绘制的六张合成插图。页面截图只能使用这些插图和演示索引，不使用私人相册。

## 不公开内容

- 个人照片、上传的参考图、私人文件名和文件路径。
- `product_data/` 下的向量、图片元数据与已有索引。
- `hf_cache/`、预训练模型缓存、训练数据和训练权重。
- `.env`、`.streamlit/secrets.toml`、访问令牌及本机环境配置。
- 虚拟环境、IDE 配置、临时文件、日志与 Python 缓存。

本机照片不会因为运行应用而自动上传 GitHub。只有 Git 提交并推送的文件才会公开；因此只依赖 `.gitignore` 不够：已经被跟踪的文件仍可能上传。

## 数据与网络

应用使用本机 PyTorch 模型进行图像编码，不调用远程图片推理 API。下载模型会向 Hugging Face 发出请求；完整缓存后可设 `HF_HUB_OFFLINE=1` 离线使用。默认关闭 Streamlit 使用统计和 Hugging Face Hub telemetry。浏览器显示图片时，运行程序的电脑会把图片发送到访问该页面的浏览器，因此默认只监听 `127.0.0.1`，不要开放端口或把私人实例部署到共享服务器。

公开源码不能代替访问控制；外部部署、第三方库或环境变化可能改变网络行为。需要处理敏感图片时，使用离线模式并自行审计运行环境。

## 上传前检查

```powershell
git status --short
git ls-files
python scripts/check_release.py --require-git
git diff --cached --check
```

发布检查使用文件白名单，并查找明显的凭据字符串，不读取本机相册。演示插图可由脚本重新生成；页面截图仍需要人工确认不含私人图像、姓名或路径。不要使用 `git add -f` 绕过忽略规则。

若发现私人文件，不要推送；先从待提交清单中移除。若已经公开，删除当前版本不等于删除 Git 历史，需另行清理历史与轮换泄露凭据。
